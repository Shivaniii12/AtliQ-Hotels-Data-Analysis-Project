# AtliQ-Hotels-Data-Analysis-Project

## 🎯 Objectives
- Perform **Exploratory Data Analysis (EDA)** on hospitality datasets
- Answer **business and data-related questions**
- Identify trends in:
  - Revenue
  - Occupancy
  - Booking patterns
  - Customer segments
- Build **meaningful visualizations** to support insights

---

## 📊 Analysis Performed
- Data cleaning and preprocessing
- Handling missing and inconsistent values
- Feature understanding and transformation
- Univariate and multivariate analysis
- Business-focused insights from data

---
## 🧠 Key Insights
- Identified patterns in hotel bookings and revenue generation
- Analyzed performance differences across room types and hotels
- Observed trends related to occupancy rates and customer behavior
- Highlighted areas with potential for operational improvement
